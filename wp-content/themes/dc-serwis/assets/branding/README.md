# DC Serwis — logo 1.2

Autorski znak DC w pomarańczu #ff7a1a i srebrze #bec5ca, z trzema liniami przepływu powietrza. Kształty nawiązują do technicznej geometrii witryny. Litery i kolory są czytelne na grafitowym tle; logotyp „Damian Cebula / Serwis Klimatyzacji i AGD” obok znaku pozostaje natywnym tekstem HTML.

- `dc-mark.svg` — źródło wektorowe, automatycznie używane w nagłówku, gdy nie ustawiono własnego logo.
- `dc-mark.png` — przezroczysty PNG do biblioteki mediów.
- `dc-icon.png` — kwadratowy PNG 512×512 do ikony witryny i logo organizacji w Rank Math.

Własne logo: Wygląd → Dostosuj → Tożsamość witryny. W WordPressie wgrywaj PNG; nie trzeba zezwalać na przesyłanie dowolnych SVG. Znak domyślny jest zaufanym lokalnym plikiem motywu.
